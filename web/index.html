Receive help requests (families, IT departments)

Create your help channel once. People you help get a personal HelpMe with a “Request help” button: their request, with the code, appears on your page. Requests are encrypted for you only.

Built to be safe

  • End-to-end encryption.
  • A code dies after 3 wrong attempts.
  • No account, no password, no unattended access.
  • Open source (AGPL-3.0): github.com/webgisman/helpme

Beware of scams

Never run HelpMe because someone called you out of the blue.

FAQ

Windows says “Windows protected your PC”.
HelpMe is not code-signed yet.

Administrator prompts?
Windows blocks remote input on elevated windows.

Deploying in a company?
Create a channel, deploy HelpMe.exe with helpme.json.
